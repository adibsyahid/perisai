## Done
### P0 Web setup (14 Oct)
- Tagged the Flutter work as `flutter-p0`. The Flutter files were moved out of the project to
  `C:\Projects\perisai-flutter-backup` (not deleted). Ahmad can delete that folder once happy; git still has everything.
- Scaffolded with `create-next-app` (TS, Tailwind, ESLint, App Router, `src/`, Turbopack) in a temp folder, then moved in.
  `cacheComponents` and `partialPrefetching` are on (create-next-app defaults).
- shadcn/ui (`base-nova` style, Base UI primitives) with `components.json`. Only `Button` is added so far,
  resized to 56px tall / 16px radius for elderly users.
- Packages added: shadcn deps (`@base-ui/react`, `class-variance-authority`, `cn`, `lucide-react`, `tw-animate-css`), `motion`.
  `cn` is the official shadcn-ui class merger (replaces clsx + tailwind-merge).
- Design tokens in `src/app/globals.css`: BLUEPRINT colours (navy, Perisai Blue, surface, danger, warning, safe, radar),
  shadcn variables mapped to them, 18px body text, 20px cards, reduced-motion rule.
- Font: Plus Jakarta Sans via `next/font/google` (self-hosted at build time).
- i18n: `src/lib/i18n/bm.ts` (default, source of keys), `en.ts` (same shape, type-checked), `index.tsx`
  (`I18nProvider` + `useI18n()`). Language is saved in localStorage on the phone and also sets `<html lang>`.
- Layout: phone-width column (max 480px) centred on laptops. `(tabs)` route group with a bottom nav:
  `/` Utama, `/keluarga`, `/radar` (dark command-centre look, the nav turns dark too), `/tetapan` (BM/EN switch).
  Placeholder "Sedang dibina" cards show where each phase's feature goes.
- PWA: `src/app/manifest.ts`, icons in `public/icons/` (generated by `node scripts/make-icons.mjs` from one shield design),
  `src/app/icon.svg` favicon, Apple touch icon, `public/sw.js` (install/activate only, no offline cache on purpose),
  registered by `src/components/sw-register.tsx`.
- Security headers in `next.config.ts` (nosniff, frame DENY, referrer policy, no-cache + CSP on `sw.js`).
- Checked in the Browser pane at 375×812: all 4 tabs, BM→EN switch and back, language survives reload, Radar dark,
  no console errors, SW active, manifest has 3 icons. `npm run lint`, `npx tsc --noEmit`, `npm run build` all clean.
